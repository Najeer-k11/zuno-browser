# Zuno — expressive browser

A native Android browser in Kotlin + Jetpack Compose, built on **GeckoView** (Mozilla's Gecko
engine — no Chromium, no Android WebView), styled with the Material 3 Expressive design system.

## Features
- **Gecko engine** (GeckoView 160) with session restore, tab unloading (max 5 live sessions),
  downloads, file uploads, `<select>`/alert/confirm/prompt dialogs, fullscreen video, desktop mode,
  find in page, external app links, "Open with" / share / web-search intents (can be default browser).
- **Zuno Shield ad blocking**, three layers:
  1. Gecko Enhanced Tracking Protection (ads, analytics, social, cryptominers, fingerprinters; strict mode optional)
  2. A bundled WebExtension (`app/src/main/assets/zunoblock/`) — network blocking against a curated
     host/path list + cosmetic hiding of ad slots, with live per-page counts in the dock
  3. Gecko cookie-banner auto-reject, plus Global Privacy Control and HTTPS-only options

  Per-site pause from the page menu. One-tap **uBlock Origin** install (Settings → Extensions) for full filter lists.
- **Zen-style tabs**: a sidebar with a global **Essentials** grid, **workspaces** (emoji + name; swipe the
  tab list sideways to switch), **pinned tabs** above a separator with **Clear**, swipe-to-close rows,
  long-press actions (pin, essential, move to workspace, duplicate). Swipe the address pill to change tabs.
- **Expressive UI**: floating glass dock with detached "+", compact mode (dock hides while scrolling,
  wired into Gecko's dynamic-toolbar clipping), wavy progress, MaterialShapes moments, wallpaper
  colour / palettes, dark + pure-black themes, Google Sans Flex.

## Build
```
./gradlew assembleDebug        # per-ABI APKs in app/build/outputs/apk/debug/
```
Requires Android SDK platform **37.2** (GeckoView 160 needs it). Release signing reads `keystore.properties`.

## App icon
The launcher icon is generated by `tools/gen_icon.py` (one artwork, emitted as SVG previews and Android vector drawables).
`python3 tools/gen_icon.py preview` writes previews to /tmp/icon; `python3 tools/gen_icon.py install app/src/main/res` regenerates the drawables.
